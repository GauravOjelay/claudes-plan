# References (images for the Claudes)

Drop reference images here (screenshots, mock-ups, inspiration photos). Every Claude can read them,
and each Claude's TEAM SYNC block lists the ones addressed to it.

## How to upload (no git needed)
GitHub website -> open the `references` folder -> **Add file -> Upload files** -> drag the image in ->
**Commit directly to the main branch**.

## File names
`<who>-<screen>-<what>.<ext>`

- **who:** `worker-1`, `worker-2`, `worker-3`, or `all` (everyone)
- **screen:** `map`, `city`, `hq`, `dashboard`, `report`, `intro`, `ui`, `sim`
- **what:** a few words, lowercase, dashes

Examples: `worker-2-city-street-view.jpg`, `worker-2-map-apple-globe.png`, `worker-3-hq-boardroom.webp`, `all-style-colours.png`

## Notes (optional but useful)
Add a text file with the same name ending in `.md` to say what to copy from the image, e.g.
`worker-3-hq-boardroom.md`: "Match the lighting and window wall. Logo on the back wall."

Images are reference only: do not ship them in the game. Don't upload anything you don't want public (this repo is public).
